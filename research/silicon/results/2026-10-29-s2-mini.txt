# ESP32-S2 Mini — ESP32-S2FN4R2 rev 1.0: single core, 320 KB SRAM, 4 MB flash and 2 MB quad PSRAM in the package
# firmware: firmware/ SEEDSIGNER_S2_MINI (and variant NOPSRAM). Stock MicroPython 1.27.0 (stock auto-growing heap)
#           + native crypto; embit, urtypes, logging, this repo's src/ and the SeedSigner app frozen.
#           micropython.bin 1,378,544 B (PSRAM) / 1,372,848 B (PSRAM off), 32% of the 1.9 MB app slot free.
# run: 2026-10-29, hard reset before each run, each configuration run twice (matching within a few ms).
#
# Five configurations, in the order tried. The board as committed is the third: 240 MHz, 16 KB caches, PSRAM.
#   1. 160 MHz (stock S2 sdkconfig), 8 KB I + 8 KB D cache (IDF default), PSRAM   sign 2,934 ms
#   2. 240 MHz,                      8 KB + 8 KB,                          PSRAM   sign 2,769 ms
#   3. 240 MHz,                     16 KB + 16 KB,                         PSRAM   sign   818 ms
#   4. 240 MHz,                      8 KB + 8 KB,                      PSRAM off   sign 2,954 ms, fits (28 KB low-water)
#   5. 240 MHz,                     16 KB + 16 KB,                     PSRAM off   OSError: can't create thread
# The clock barely matters; the caches do. Code and constant tables run from flash through them.
# Run 5 fails at Controller.get_instance(): BackgroundImportThread's 32 KiB stack needs one internal block, and
# the largest left after the 16 KB of extra cache is 25.6 KB.
