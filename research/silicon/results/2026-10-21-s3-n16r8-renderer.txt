# This repo's text renderer + bridge on the device -- C3 proxy (PSRAM off), src/ frozen
# firmware: firmware/ SEEDSIGNER_S3_DEVKIT, variant NOPSRAM, micropython.bin 1,411,376 B. run: 2026-10-21.
#
# First time the renderer ran on MicroPython. Getting here took four fixes, each now covered by
# tests/test_micropython_imports.py: an unguarded `typing` import; `textwrap` (status screen) and `base64`
# (bridge) which MicroPython doesn't ship; str.center/format padding, which MicroPython measures in UTF-8
# bytes (a line with a check mark came out 18 wide on a 20-column LCD) and splits odd margins the other way;
# and the passphrase keyboard's charsets in a dict, whose order MicroPython doesn't keep (it opened on
# symbols). After them, all 12 frames below (6 screens x 2 tiers) match CPython byte for byte.
#
# 'alloc' is each step's peak with GC off; 'retained' is what stays after a collect (negative = noise from
# the previous step's garbage). int_free doesn't move: rendering never grows the heap.
